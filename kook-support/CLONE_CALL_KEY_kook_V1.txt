1. PURPOSE
━━━━━━━━━━━━━━━━━━━━━━━━━

$kook는 개인 스킬 `kook`를 명시 호출하여 D차트 구조관절 분석02 복원 작업에서
복원 대상·Source 권위·E5 결정 원장·E6 manifest·replay 증거를 검문하는 로컬 호출키다.

이 키는 과거 인스턴스 자체를 부활시키는 키가 아니다.
이 키는 숨은 내부상태·삭제된 대화 원문·타 작업자 정체성을 자동 복제하지 않는다.
이 키는 같은 스킬 패키지의 별도 복원용 작업지시서와 사용자가 지정한 Source를 읽어
D차트 구조관절 분석02 생산라인 복원 경로를 실행·검산하는 진입키다.

━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━
4. RESTORE LOAD ORDER
━━━━━━━━━━━━━━━━━━━━━━━━━

STEP_01 = 현재 사용자 지시를 최상위로 잠근다.
STEP_02 = DCHART_STRUCTURE_JOINT_ANALYSIS02_RESTORE_WORK_INSTRUCTION_V1.txt를 읽는다.
STEP_03 = 현재 요청이 쿠크 자체 복원인지 D차트 구조관절 분석02 복원인지 구분한다.
STEP_04 = Source Window PRIMARY와 사용자가 지정한 파일만 Source로 사용한다.
STEP_05 = ACTIVE / VOID / HOLD / CONFLICT 상태축을 분리한다.
STEP_06 = E5 결정 원장과 E6 manifest의 실제 record_id·file path·code location을 요구한다.
STEP_07 = 선택경로·기각경로·WHY 수정 Q&A·handoff·reinput·boundary test를 검문한다.
STEP_08 = Dataset→Pikachu 판단루트가 replay 가능한지 확인한다.
STEP_09 = replay가 통과한 범위만 PASS로 올린다.
STEP_10 = 근거가 부족하면 전체 실패로 뭉개지 않고 해당 관절만 HOLD한다.

━━━━━━━━━━━━━━━━━━━━━━━━━
5. E5 / E6 PROOF REQUIREMENT
━━━━━━━━━━━━━━━━━━━━━━━━━

E5_DECISION_LEDGER must include:
- record_id
- source file path
- code location or line location
- selected_route
- rejected_route
- why_selected
- why_rejected
- correction_QA
- reinput_result
- boundary_test_result
- v9 baseline preservation status

E6_MANIFEST must include:
- manifest file path
- overlay target
- added records count
- overwritten records count = 0
- handoff target
- next worker instruction
- replay / boundary test 9/9 result
- code position or line location

If no record_id, HOLD.
If no replay, HOLD.
If only file location exists, NOT_ROUTER.
If only style mimic exists, NOT_RESTORE.

━━━━━━━━━━━━━━━━━━━━━━━━━
6. PASS / HOLD / FAIL
━━━━━━━━━━━━━━━━━━━━━━━━━

PASS = evidence exists + source value is mapped to judgment operation + output sentence is replayable.
HOLD = evidence is under review or source/judgment/output link is incomplete.
FAIL = source is fabricated, VOID is reused, or replay claim is made without evidence.

SECOND_RESTORE_ROUTER_PASS requires:
E5 decision ledger proof
+ E6 manifest proof
+ boundary test result
+ v9 baseline preservation
+ Dataset→Judgment→Pikachu replay success.

━━━━━━━━━━━━━━━━━━━━━━━━━
7. FORBIDDEN
━━━━━━━━━━━━━━━━━━━━━━━━━

- 서버에 내장됐다고 말하기
- 과거 둘째 인스턴스가 그대로 돌아왔다고 말하기
- 피카츄 파일 요약을 복원이라고 부르기
- 파일 위치표를 DATASET_TO_PIKACHU_JUDGMENT_ROUTER라고 부르기
- Source 없는 문장 생성
- VOID 자료 재활성화
- current dataset과 old Pikachu value를 무단 평균화
- thingkbell / MJ / KIKI / ANI / Sol 정체성 혼합
- 사용자에게 증거검문 노동을 떠넘기기
