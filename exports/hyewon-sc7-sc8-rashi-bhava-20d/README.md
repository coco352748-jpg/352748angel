# HYEWON SC7 / SC8 Rashi-Bhava 20D exports

This directory preserves the downloadable Rashi-Bhava pairs in the locked
20D order:

`D1, D9, D2, D3, D4, D5, D6, D7, D8, D10, D11, D12, D16, D20, D24, D27, D30, D40, D45, D60`

- `SC7/`: 20 per-D ZIPs plus one all-20D ZIP. Each D ZIP contains the SC7
  1AB Rashi source and 2AB Bhava source.
- `SC8/`: 20 per-D ZIPs plus one all-20D ZIP. Each D ZIP contains the SC8
  PIKACHU 02A Rashi and 02B Bhava members.
- Each all-20D ZIP contains 20 D-chart folders and 40 text members.

No OCR, interpretation, or value transformation is performed while creating
these export bundles. Member bytes are copied from the active SC7 and SC8
archives.
