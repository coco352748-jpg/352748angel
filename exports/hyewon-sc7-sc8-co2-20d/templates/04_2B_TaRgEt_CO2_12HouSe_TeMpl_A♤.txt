분할차트 12하우스 공동장 구조 체크 슬롯

━━━━━━━━━━━━━━━━━━━━━━━━━

Purpose =
Target D-chart 안에서 1H~12H 각각의 같은 sign / 같은 house 안의 공동장을 확인한다.

Core Rule =
- Target D-chart Rashi 공동장은 해당 D차트의 원본 구조다.
- Target D-chart Bhava 공동장은 현실 house-function 적용층에서 공동장이 유지되는지 / 분리되는지 / 재기능화되는지 확인하는 보정층이다.
- RASHI_ONLY판에서는 Bhava 공동장을 적용하지 않는다.
- BHAVA_ONLY 또는 RASHI_BHAVA_INTEGRATED판에서만 Bhava 공동장 비교를 수행한다.
- 공동장은 “같이 있다”로 쓰지 않는다.
- 앞도수 행성이 무엇을 열고, 뒤도수 행성이 무엇을 압축하는지 쓴다.
- 각 행성의 독립 기능과 상호착색을 분리한다.
- Bhava에서 공동장이 유지되는지 / 분리되는지 반드시 다시 확인한다.
- 단일 행성은 공동장으로 쓰지 않는다.
- 빈 하우스는 Lord-only operation으로 넘긴다.
- 기능어 사용 금지.
- 현실 언어 번역 금지.
- 강도층 / Aspect / Dasha 적용 금지.
- 해석 확장 금지.
- 이 슬롯은 공동장 구조만 확인한다.

0-1. PANEL TYPE APPLICATION RULE
패널 타입 적용 분기 규칙
━━━━━━━━━━━━━━━━━━━━━━━━━

RASHI_ONLY =
- Rashi 1H~12H Co-presence Packet만 사용한다.
- Bhava Co-presence Comparison Slot은 사용하지 않는다.
- Bhava 유지/분리/재기능화 문장을 만들지 않는다.

BHAVA_ONLY =
- Bhava 1H~12H Co-presence Slot만 사용한다.
- Rashi Source Link가 없으면 Rashi 원본 구조를 추정하지 않는다.
- Rashi 비교문은 SUPPORT_ONLY 또는 NOT_USED로 둔다.

RASHI_BHAVA_INTEGRATED =
- Rashi Co-presence Packet을 먼저 작성한다.
- 그다음 Bhava Co-presence Comparison Slot을 작성한다.
- Rashi 원본 공동장을 Bhava로 덮어쓰지 않는다.
- Bhava 현실 적용층이 Rashi 원본 공동장을 대체하지 않는다.

0-2. MISSING / NOT VISIBLE RULE

━━━━━━━━━━━━━━━━━━━━━━━━━

- Bhava placement가 보이지 않으면 NOT_VISIBLE로 둔다.
- Bhava comparison sentence를 만들지 않는다.
- Rashi co-presence만 보이는 경우 RASHI_ONLY로 처리한다.
- Degree가 보이지 않으면 Degree Order / Gap을 추정하지 않는다.
- Nakshatra / Pada가 보이지 않으면 NOT_SHOWN으로 둔다.
- RL/NL/SL/SSL이 보이지 않으면 회로를 만들지 않는다.
- Source 없는 값은 SUPPORT_ONLY도 아니고 NOT_USED로 둔다.

CO-PRESENCE =

- Degree Order / Gap / Independent Function / Mutual Coloring을 반드시 작성한다.
- 공동장은 “같이 있다”로 쓰지 않는다.
