0-1. CORE RULE
━━━━━━━━━━━━━━━━━━━━━━━━━
- Rashi 공동장은 원본 구조다.
- Bhava 공동장은 현실 house-function 적용층에서 공동장이 유지되는지 확인하는 보정층이다.
- 공동장은 “같이 있다”로 쓰지 않는다.
- 앞도수 행성이 무엇을 열고, 뒤도수 행성이 무엇을 압축하는지 작성한다.
- 각 행성의 독립 기능과 상호착색을 분리한다.
- Bhava에서 공동장이 유지되는지 / 분리되는지 / 부분 유지되는지 / 재기능화되는지 반드시 다시 확인한다.
- 단일 행성은 공동장으로 쓰지 않는다.
- 빈 하우스는 공동장 없음 / Lord-only operation으로 넘긴다.
- 기능어 사용 금지.
- 현실 언어 번역 금지.
- 강도층 / Aspect / Dasha 적용 금지.

4. SINGLE / EMPTY / CO-PRESENCE RULE
━━━━━━━━━━━━━━━━━━━━━━━━━
SINGLE =
- 점유 행성이 1개인 경우 공동장 해석을 만들지 않는다.
- 단일 행성의 도수 / 파다 / 회로 / 로드 이동만 확인한다.
- 단일 행성은 공동장으로 부르지 않는다.

EMPTY =
- 점유 행성이 없는 경우 공동장 없음으로 처리한다.
- 해당 하우스는 Lord-only operation으로 후속 단계에서 처리한다.

CO-PRESENCE =
- 점유 행성이 2개 이상일 때만 공동장 체크를 수행한다.
- Degree Order / Gap / Independent Function / Mutual Coloring을 반드시 작성한다.
