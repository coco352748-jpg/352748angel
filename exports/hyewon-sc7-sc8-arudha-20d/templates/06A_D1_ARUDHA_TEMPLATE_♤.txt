ROLE =
- 이 문서는 D1 Arudha / Surface Structure를 1H~12H별로 적용하기 위한 D1 전용 슬롯 템플릿이다.
- D1 Arudha는 D1 실제 구조가 외부 인식·표면 장부·보이는 결과에서 어떻게 드러나는지 확인하는 표면화층이다.
- D1 Arudha는 D1 Rashi 원본 구조를 덮어쓰지 않는다.
- D1 Arudha는 D1 Bhava 현실 적용층을 덮어쓰지 않는다.
- D1 Arudha는 사건 약속을 새로 만들지 않는다.
- D1 Arudha는 실제 구조가 아니라 표면화 구조다.
- 이 단계에서는 강도층 / Aspect / Dasha / AVA / Bhinna / Ashta / Varga Link를 적용하지 않는다.
MASTER ORDER POSITION =
- Step 6 = D1 ARUDHA / SURFACE STRUCTURE
- Step 0 Source Call 이후 사용한다.
- Step 1 D1 Rashi Source Slot 이후 사용한다.
- Step 2 D1 Bhava Source Slot 이후 사용한다.
- Step 3 D1 Rashi + Bhava First Integration 이후 사용한다.
- Step 4 D1 Co-presence Check 이후 사용 가능하다.
- Step 7 Strength 1st Correction 이전에 표면화 구조만 잠근다.

SOURCE FAMILY LOCK =
- D1 Rashi = 실제 원본 구조 / 사건 약속
- D1 Bhava = 현실 house-function 적용층
- D1 Arudha = 외부 인식 / 표면 장부 / 보이는 결과 / surface projection
- UL = 관계·배우자·결합·계약 표면화 독립 슬롯
- Arudha는 Rashi/Bhava를 대체하지 않는다.
- Arudha는 D차트 원본 구조처럼 취급하지 않는다.
- Arudha는 surface layer로만 사용한다.
CORE RULE =
- D1 Arudha 12H는 A1/AL~A12를 하우스별로 보존한다.
- UL은 A12가 아니라 독립 슬롯으로 둔다.
- 각 Arudha Pada는 해당 D1 house matter가 외부에 어떻게 보이는지 확인한다.
- Arudha Sign / Arudha House / Arudha Lord / Arudha Lord Position을 분리한다.
- Rashi/Bhava source와 Arudha surface를 분리한다.
- 표면 구조가 실제 구조와 같아 보이더라도 실제 구조를 대체하지 않는다.
- 표면 구조가 실제 구조와 다르면 Surface Split / Surface Distortion / Surface Displacement로 기록한다.
- 해석 확장 금지.
- 기능어 사용 금지.
- 현실처방 금지.
MISSING / NOT VISIBLE RULE =
- Arudha Pada가 NOT_SHOWN이면 계산하거나 추정하지 않는다.
- Arudha Sign이 없으면 Arudha House를 만들지 않는다.
- Arudha Lord가 없으면 Lord Movement를 확정하지 않는다.
- D1 Rashi Link가 없으면 Surface Source Comparison을 HOLD로 둔다.
- D1 Bhava Link가 없으면 Reality Surface Comparison을 HOLD로 둔다.
- UL이 없으면 UL slot은 NOT_USED로 둔다.

- DERIVED_UNCHECKED는 REFERENCE_ONLY 또는 HOLD로 둔다.
