D-STRUCTURE SOURCE BOARD OUTPUT RULE
- 전체 D-Arudha point를 먼저 보존한다.
- 하우스별 해석은 하지 않는다.
- 특정 Target House 적용은 다음 슬롯에서 한다.
- SOURCE_PRESERVED는 원자료 보존 상태를 뜻하며, 해석 적용 완료를 뜻하지 않는다.
- PARTIAL은 source 일부가 보이지만 핵심 필드가 부족한 상태다.
- NOT_SUPPLIED / NOT_USED는 해당 point를 실제 적용하지 않는다.
- Source House와 Pada Landing House를 섞지 않는다.
- 같은 위치에 여러 A-point가 있어도 병합하지 않는다.

DOCUMENT ROLE
- 이 블록은 D-Apoint의 원천 하우스와 실제 표면 착지 위치를 분리한다.
- Arudha point는 “해당 하우스 자체”가 아니라 “해당 하우스 기능이 밖에서 보이는 표면 위치”다.
- 따라서 D-A2는 2H의 표면 point이고, D-A2가 실제로 떨어진 sign/house는 별도로 읽는다.
- Source House와 Landing House를 섞지 않는다.
- Landing House가 Target House와 다르다고 해서 point를 폐기하지 않는다.
- Landing House가 Target House와 같다고 해서 실제 구조와 표면 구조가 완전히 같다고 단정하지 않는다.

RULE
- Source House = 무엇의 표면인가
- Landing House = 어디에 보이는가
- Actual Target Structure = 실제 구조가 어디서 작동하는가
- Surface Channel = 외부 인식이 어디를 통해 형성되는가
- Source House와 Landing House가 같으면 SAME 후보가 될 수 있으나 자동 SAME은 아니다.
- Source House와 Landing House가 다르면 DIFFERENT / PARTIAL / SPLIT 후보가 되지만 자동 폐기는 아니다.
- Arudha는 실제 구조를 바꾸지 않고, 실제 구조가 외부에서 어느 위치로 비쳐 보이는지만 보정한다.

6. ACTUAL-SURFACE CHECK
━━━━━━━━━━━━━━━━━━━━━━━━━
- 《Actual-Surface Status》 = <SAME / DIFFERENT / PARTIAL / SPLIT / NEEDS_RECHECK>
- 《Source-Landing Status》 = <SAME_HOUSE / DIFFERENT_HOUSE / PARTIAL / SPLIT / NOT_CHECKED>
- 《Surface Agreement》 = <YES / NO / PARTIAL / NOT_CHECKED>
- 《Surface Distortion》 = <NONE / OVER-VISIBLE / UNDER-VISIBLE / MISPLACED / SPLIT>
- 《Use Decision》 = <APPLY_AS_SURFACE / APPLY_AS_SURFACE_AS_DISTORTION / SUPPORT_ONLY / REFERENCE_ONLY / HOLD / NOT_USED>
판정 기준 =
- 《SAME》 = 실제 Target House 구조와 Arudha 표면이 같은 방향으로 보인다.
- 《DIFFERENT》 = 실제 구조와 표면 인식이 다른 하우스 기능으로 보인다.
- 《PARTIAL》 = 일부는 일치하지만 핵심 기능이 완전히 같지는 않다.
- 《SPLIT》 = 실제 구조와 표면 구조가 둘 이상의 기능으로 갈라진다.
- 《NEEDS_RECHECK》 = Source / Degree / House From Lagna / Bhava Link가 부족하다.
표면 왜곡 기준 =
- 《NONE》 = 실제 구조와 표면이 왜곡 없이 보인다.
- 《OVER-VISIBLE》 = 실제보다 표면에서 과하게 보인다.
- 《UNDER-VISIBLE》 = 실제보다 표면에서 덜 보인다.
- 《MISPLACED》 = 실제 기능과 다른 표면 위치로 보인다.
- 《SPLIT》 = 여러 표면으로 분리되어 보인다.
Source-Landing 기준 =
- 《SAME_HOUSE》 = Source House와 Pada Landing House가 같은 하우스 계열로 보인다.
- 《DIFFERENT_HOUSE》 = Source House와 Pada Landing House가 다른 하우스 기능으로 보인다.
- 《PARTIAL》 = Source House와 Landing House가 일부 기능만 공유한다.
- 《SPLIT》 = 하나의 표면 point가 둘 이상의 표면 채널로 갈라진다.
- 《NOT_CHECKED》 = Source House 또는 Landing House 정보가 부족하다.

LEVEL 1 SLOT JUDGEMENT SENTENCE =
《<D_CHART_TAG> <RELEVANT_ARUDHA_POINT>》는 해당 분할차트 실제 《<TARGET_HOUSE> <TARGET_ACTUAL_FUNCTION>》을 대체하지 않고,
그 구조가 해당 D차트 도메인 안에서 외부 인식과 표면 장부에 《<SURFACE_THEME>》로 어떻게 보이는지 확인하는 표면화 보조층이다.
이때 《Source House of Pada》는 “무엇의 표면인가”를 뜻하고,
《Pada Landing House》는 “어디에 보이는가”를 뜻하므로,
두 값을 섞지 않는다.
실제 《<TARGET_HOUSE>》 구조와 《<RELEVANT_ARUDHA_POINT>》 표면 구조가 같으면 《SAME》으로 두고,
갈라지면 《DIFFERENT / PARTIAL / SPLIT》로 표기하며,
최종 구조판정은 해당 분할차트 Rashi/Bhava와 D1 본체 약속을 기준으로 유지한다.
LEVEL 2 DEF_BOARD SURFACE NOTE =
《<D_CHART_TAG> <TARGET_HOUSE>》의 실제 구조는 《<TARGET_RASHI_LINK>》와 《<TARGET_BHAVA_LINK>》를 기준으로 유지하고,
《<RELEVANT_ARUDHA_POINT>》는 그 구조가 외부에서 《<SURFACE_FUNCTION>》으로 보이는 방식만 보정한다.
따라서 이 표면값은 사건 약속을 새로 만들지 않고,
실제 구조가 표면에서 《<OVER-VISIBLE / UNDER-VISIBLE / MISPLACED / SPLIT / NONE>》로 드러나는지 확인하는 데만 사용한다.

9. USE DECISION
━━━━━━━━━━━━━━━━━━━━━━━━━
- 《APPLY_AS_SURFACE》 =
  해당 Arudha point가 해당 타깃 하우스의 외부 인식과 표면 장부를 유효하게 보정할 때 사용한다.
- 《APPLY_AS_SURFACE_AS_DISTORTION》 =
  실제 구조와 표면 구조가 다르지만, source가 명확하고 그 차이가 중요한 표면 왜곡 정보일 때 사용한다.
- 《SUPPORT_ONLY》 =
  실제 구조를 보조 설명할 수 있으나, 구조판정에 직접 반영하지 않을 때 사용한다.
- 《REFERENCE_ONLY》 =
  값은 보존하지만 현재 하우스 판정에는 쓰지 않을 때 사용한다.
- 《HOLD》 =
  Source Confidence 부족, Degree/Nakshatra/Pada 누락, Actual-Surface Status 불명확, Target Rashi/Bhava link 미확인일 때 사용한다.
- 《NOT_USED》 =
  해당 포인트 자료가 없거나 현재 질문 범위에 포함되지 않을 때 사용한다.

- SAME + Source Complete → APPLY_AS_SURFACE
- PARTIAL + Source Complete → APPLY_AS_SURFACE or SUPPORT_ONLY
- SPLIT + Source Complete → SUPPORT_ONLY / HOLD
- DIFFERENT + Source Complete → APPLY_AS_SURFACE_AS_DISTORTION
- DIFFERENT + Source Weak → REFERENCE_ONLY / HOLD
- NOT_SHOWN → NOT_USED

  source가 명확하면 DIFFERENT도 중요한 Surface Distortion으로 적용한다.
- 단, DIFFERENT가 실제 구조를 덮어쓰지는 않는다.

- D1 Anchor는 Source Weak / Derived Unchecked / NOT_SHOWN 상태의 Target Arudha point를 보정 생성하지 않는다.
- D1과 Target D-chart Arudha가 같은 방향이면 Surface Agreement 보강값으로만 사용한다.
- D1과 Target D-chart Arudha가 다르면 Surface Distortion / DIFFERENT / SPLIT 검산값으로만 사용한다.
- 최종 구조판정은 D1 본체 약속 + Target D-chart Rashi/Bhava 위계로 유지한다.
